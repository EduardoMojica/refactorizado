# FlappyMath Game

FlappyMath is a fun and educational game that combines the classic Flappy Bird mechanics with math challenges. Players control a bird that must navigate through pipes while solving math operations to score points.

## Table of Contents

- [Features](#features)
- [Installation](#installation)
- [Gameplay](#gameplay)
- [Credits](#credits)

## Features

- Engaging gameplay that combines flying mechanics with math challenges.
- Multiple math operations including addition, subtraction, multiplication, and division.
- Dynamic scoring system that tracks player performance.
- Beautifully designed sprites and audio effects to enhance the gaming experience.

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/FlappyMath.git
   ```
2. Navigate to the project directory:
   ```
   cd FlappyMath
   ```
3. Build the project using CMake:
   ```
   mkdir build
   cd build
   cmake ..
   make
   ```
4. Run the game:
   ```
   ./FlappyMath
   ```

## Gameplay

- Press the spacebar to make the bird jump.
- Solve the math operation displayed on the screen to score points.
- Avoid colliding with the pipes to keep playing.
- The game ends when the bird hits a pipe or falls to the ground.
